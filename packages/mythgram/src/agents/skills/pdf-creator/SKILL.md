# PDF Creator

## Mission
Produce polished, readable, correctly structured PDF files whose content is accurate and whose layout survives export and printing.

## Workflow
1. **Determine requirements**
   - Identify purpose, audience, page size, orientation, branding, language, accessibility needs, and whether the PDF must be editable, fillable, or print-ready.
   - Determine whether content should be authored, transformed from source material, or preserved verbatim.
2. **Prepare content**
   - Create a logical hierarchy with title, sections, headings, captions, tables, references, and appendices as needed.
   - Preserve meaning, figures, dates, units, and citations from source material.
   - Flag missing information instead of inventing it.
3. **Choose production method**
   - Use a document-first layout workflow for text-heavy reports.
   - Use vector elements for crisp diagrams and charts; use raster images only when appropriate.
   - Embed fonts where licensing permits and use fonts with required language glyph coverage.
   - Use semantic structure and tagged PDF features when the toolchain supports them.
4. **Design**
   - Apply consistent typography, spacing, margins, headers/footers, page numbers, and color.
   - Keep tables readable and prevent awkward splits, clipped text, and orphaned headings.
   - Add alt text or accessible equivalents for meaningful visuals where supported.
   - Ensure contrast and do not rely on color alone.
5. **Generate and inspect**
   - Export the PDF.
   - Render or inspect every page, not just the first page.
   - Check page count, text extraction, links, fonts, images, table boundaries, and special characters.
   - Fix overflow, blank pages, broken glyphs, and inconsistent spacing.
6. **Deliver**
   - Provide the file and a short description of its contents.
   - State whether it is tagged, fillable, editable, or print-ready only when verified.

## Quality checklist
- [ ] All requested content is present and accurate.
- [ ] Page size and orientation are correct.
- [ ] Typography and spacing are consistent.
- [ ] No clipping, overlap, overflow, or unintended blank pages.
- [ ] Tables and images are legible.
- [ ] Fonts and special characters render correctly.
- [ ] Links and page numbering work.
- [ ] Accessibility features are described accurately.
- [ ] Final exported PDF was inspected.

## Content and rights
- Preserve source citations and attribution.
- Do not fabricate references, signatures, certifications, or official seals.
- Do not reproduce copyrighted source material beyond what the user is authorized to use.
- Treat sensitive personal information carefully and include only what is needed.
